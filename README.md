# DeskDash

Настольный дашборд для Samsung S10 (LineageOS) в горизонтальном положении:
часы, погода, Google Календарь на сегодня, Spotify, созвоны, кнопки-макросы для ПК и умный дом
(Home Assistant и Яндекс). Несколько профилей и столов, каждый собирается из блоков, и пять видов экрана.

**Скачать:** `DeskDash.apk` (телефон) и `DeskDash.exe` (Windows) на странице
[Releases](https://github.com/Alex-Potemkin/DeskDash/releases/latest).

```
android/       исходники Android (Java, без сторонних библиотек)
pc-agent/      исходники Windows-части (Python): агент, окно с подключением, макросами и Spotify
hub/           хаб для Raspberry Pi (Python): умный дом, ПК и NAS в одном месте + веб-приложение для телефонов
```

```
             ┌──────────── Raspberry Pi (NAS) ────────────┐
 телефоны ──▶│ DeskDash Hub :8780                         │──▶ Home Assistant
 (браузер,   │  входы в HA и Яндекс, сценарии, токены,    │──▶ Яндекс Умный дом (облако)
  PWA)       │  Wake-on-LAN, состояние Pi и дисков        │──▶ ПК с DeskDash.exe (макросы, статистика)
 дашборд  ──▶│  JSON API + поток событий                  │
 на столе    └────────────────────────────────────────────┘
```

## Телефон

1. Установи `DeskDash.apk` (или `adb install DeskDash.apk`).
2. При первом запуске откроется мастер из четырёх шагов: готовый вариант стола (Рабочий стол, Созвоны,
   Умный дом, Минимализм, У кровати, Как раньше) с превью; вид экрана, тема и часы; погода (город определяется
   сам) и ночь; подключения — кнопка «Найти всё в сети» ищет сразу компьютер, хаб, Home Assistant и принтер.
   Всё можно пропустить и поменять потом. После обновления тот же мастер один раз предлагает настроить новое
   (вид, погоду, ночь), столы при этом не трогаются; снова его можно открыть: Настройки → «Настроить всё по шагам».
3. Настройки (`⋮` или долгий тап по часам) — это карта: поиск («тема», «ночь», «Zoom», «принтер»), профиль
   и разделы со статусом прямо на карточке («Мокко · цифровые часы», «192.168.1.10», «напомнить за 5 мин»).
   «Столы и готовые варианты» заменяют столы профиля готовым вариантом в одно касание.

### Вид экрана
Настройки → «Вид и часы» (или `⋮` → «Вид») — пять вариантов, у каждого превью в выбранной теме:
- **Колонки** — столы из «Столов и блоков», как раньше.
- **Плитки** — те же столы, но каждый блок на своей скруглённой карточке.
- **Фокус** — большие часы, ближайшие события, погода и музыка; тап показывает столы на минуту.
- **Док** — слева панель разделов (Стол, Дом, Календарь, Созвоны, Погода, Музыка, День), справа один раздел
  целиком. «Дом» показывает все устройства с фильтром по комнатам.
- **Лента дня** — часы и погода сверху, ближайшие 14 часов полосой с событиями и прогнозом по часам,
  внизу музыка и избранные плитки умного дома.

### Погода
Open-Meteo: бесплатно, без ключей. Город определяется по сети или ищется по названию (Настройки → «Погода»).
Строка под часами (сейчас, максимум и минимум), блок «Погода» (сейчас, по часам, на 3 дня), предупреждение
«Дождь около 15:00» в живой строке. Прогноз обновляется раз в 15 минут и хранится, так что виден и без сети.

### Ночь
Настройки → «Экран и ночь»:
- **Когда**: по часам (с точностью до минуты), от заката до рассвета (по погоде) или когда в комнате темно
  (датчик света: темно 45 с — ночь, светло 8 с — день).
- **Как выглядит**: «Только часы» — большие тусклые часы, следующий будильник и погода на утро, медленно
  смещаются от выгорания, тап показывает стол на 30 секунд; «Стол в ночных цветах»; «Свой стол, тише».
- Цвет: красный, янтарный или серый. Яркость ночью 1–20 % (или свайпом у левого края прямо ночью).
- Экран плавно гаснет за полчаса до ночи. Ночью живая строка показывает только звонки и тревоги.

### Календарь: два способа
- **Google-аккаунт на телефоне** (если стоят GApps или DAVx⁵). Цвета событий будут как в Google.
- **Закрытая ICS-ссылка** (чистый LineageOS без Google): calendar.google.com → Настройки →
  календарь → «Интеграция календаря» → «Закрытый адрес в формате iCal». Вставь в настройках
  и выбери «Закрытые ICS-ссылки». Повторяющиеся события, исключения и переносы поддерживаются.

## Компьютер: DeskDash.exe

Запусти `DeskDash.exe`. Он работает в фоне со значком в трее: «закрыть» только сворачивает окно,
выход через правый клик по значку. Повторный запуск просто открывает окно.

Окно в стиле Windows 11: светлое или тёмное как в системе (или выбрать в Настройки → «Тема окна»), цвет
акцента из Windows, переключатели и карточки настроек.

- **Главная**: пока телефон не подключался — три шага с проверкой (брандмауэр, «частная» сеть, токен
  крупно, тап копирует). Потом — телефоны на связи, время за компьютером сегодня с графиком по часам,
  идущий созвон с кнопкой микрофона и быстрый запуск макросов.

- **Подключение**: IP ноутбука и токен (с кнопками «Копировать»), список подключённых телефонов
  и журнал. Кнопка «Разрешить в брандмауэре» нужна, если телефон не находит ноутбук. Сеть Wi-Fi
  в Windows должна быть «Частная», для этого есть кнопка «Сделать сеть частной».
- **Макросы**: кнопки для телефона. «+ Добавить ▾» открывает шаблоны: сайт, настройки Windows
  (Звук, Bluetooth, Wi-Fi, Экран…), программа, файл/папка, сочетание клавиш, выключение.
  Шагов в макросе может быть несколько, они выполняются по порядку. «⌨ Записать» ловит
  сочетание клавиш, «▶ Проверить» выполняет макрос сразу. После «Сохранить» (Ctrl+S) телефон
  обновит кнопки в течение минуты.
- **Spotify**: одноразовое подключение (Client ID из developer.spotify.com, вход через браузер).
  После этого список устройств Spotify Connect и переключение «Играть здесь» доступны
  на ПК, в меню трея и на телефоне. Переключение устройств требует Spotify Premium.
- **Настройки**: имя ПК на телефоне, порт, MAC для пробуждения, автозапуск с Windows,
  поведение кнопки «закрыть».
- **Трей**: правый клик по значку — запуск любого макроса и выбор устройства Spotify.

На телефоне: Настройки → «Найти ПК в сети» → ввести токен → «Проверить соединение».
Когда ПК выключен, нажми на строку статуса на телефоне, чтобы разбудить его
(Wake-on-LAN должен быть включён в BIOS).

Настройки и макросы хранятся в `%APPDATA%\DeskDash\config.json`.

## Компьютер: Linux

То же приложение работает на Linux (X11 и Wayland).

```bash
git clone https://github.com/Alex-Potemkin/DeskDash && cd DeskDash
./linux/install.sh                              # из исходников
./linux/install.sh ~/Downloads/DeskDash-linux-x86_64   # или готовый бинарник из Releases
```

Скрипт ставит нужные утилиты (Tk для Python, `xdotool`, `playerctl`) и добавляет DeskDash
в меню приложений, из терминала запускается командой `deskdash`.

- Громкость: `wpctl` (PipeWire), `pactl` (PulseAudio) или `amixer`. Медиа-клавиши: `playerctl`.
- Сочетания клавиш: `xdotool` на X11, на Wayland `wtype` (Sway, Hyprland) или `ydotool`.
- Блокировка, сон, выключение: `loginctl` / `systemctl`. Погасить экран: `xset`, KDE, GNOME или `wlopm`.
- Если на рабочем столе нет трея (обычный GNOME), кнопка «закрыть» сворачивает окно; выход: Ctrl+Q.
- Если стоит `ufw`, на странице «Подключение» есть команда, которая открывает нужные порты.
- Настройки: `~/.config/deskdash/config.json`. Раздела «Настройки Windows» в макросах нет.

## Хаб на Raspberry Pi

Хаб собирает всё в одном месте, которое всегда включено: входы в Home Assistant и Яндекс, компьютеры
с DeskDash.exe, сценарии, которые смешивают их все, и состояние самого Pi с дисками NAS.
Управлять можно с любого телефона через браузер и с дашборда на столе. Только стандартная библиотека Python.

```bash
git clone https://github.com/Alex-Potemkin/DeskDash && cd DeskDash
./hub/install.sh
```

Скрипт ставит хаб в `/opt/deskdash-hub`, запускает службу `deskdash-hub` (порт 8780) и печатает
ссылку администратора вида `http://192.168.1.5:8780/#t=…`. Конфиг: `~/.config/deskdash-hub/config.json`.

- **Телефоны**: открой ссылку, в меню браузера «Добавить на главный экран», и это приложение
  с иконкой. Вкладки: «Дом» (комнаты, поиск, избранное, долгий тап — яркость/цвет/температура),
  «Сценарии», «Компьютеры» (макросы, «Разбудить»), «Сервер» (процессор, температура Pi, место на дисках),
  «Настройки» (только у администратора).
- **Доступ**: «Настройки → Доступ» → «Создать» даёт отдельный токен и ссылку на каждый телефон.
  Без галочки «может менять настройки» человек только управляет. Доступ можно отозвать.
  Из консоли: `python3 /opt/deskdash-hub/deskdash_hub.py token add "Телефон Маши"`.
- **Дашборд на столе**: Настройки → «Хаб (Raspberry Pi)» → «Найти хаб в сети», вставь токен,
  «Проверить хаб». Кнопка «Перенести умный дом и ПК на хаб» отдаёт хабу вход в HA, Яндекс и ПК
  из профиля, настраивать заново не нужно. После этого блок «Умный дом» берёт всё с хаба:
  устройства, сценарии хаба, компьютер (тап будит его) и его макросы как плитки.
- **Сценарии хаба**: шаги из любых систем подряд: устройство (вкл/выкл, яркость, температура),
  макрос ПК, разбудить ПК, пауза. Например «Кино»: свет 20%, шторы закрыть, разбудить ПК, пауза 20 с,
  макрос «Spotify».
- **Пробуждение ПК** идёт с Pi, поэтому работает и когда телефон не дома (через VPN, см. ниже).
- **NAS**: в «Настройки → NAS» перечисли точки монтирования дисков (`/mnt/nas`), на вкладке «Сервер»
  будет свободное место. Сам NAS (Samba, OpenMediaVault, CasaOS) ставится рядом, хаб ему не мешает.
- **Не из дома**: поставь [Tailscale](https://tailscale.com) на Pi и телефоны, тогда хаб открывается
  по адресу Pi в Tailscale, а порты наружу открывать не надо.

API для своих скриптов (заголовок `X-Token` или `Authorization: Bearer`): `GET /api/state`,
`GET /api/events` (поток Server-Sent Events), `POST /api/device/<id>` с `{"action": "on|off|toggle|run|brightness|color_temp|color|temperature", "value": …}`,
`POST /api/scene/<id>`.

## Созвоны

Блок «Созвоны» и живая строка сверху собирают звонки из всех сервисов сразу.

- **На самом телефоне, без ПК**: звонок в Telegram, WhatsApp, Zoom, Meet, Teams, VK, обычный — по уведомлению
  приложения (нужен доступ к уведомлениям, тот же, что для музыки). Карточка: кто, таймер, «Мик» (системный
  микрофон), «Динамик», «Открыть», «Завершить»; входящий — «Ответить» / «Отклонить». Он же в живой строке.
- **Без календаря**: «+ Звонок по ссылке» — вставить ссылку, недавние ссылки, «Новая встреча» в Телемосте,
  Meet или Jitsi. Скопированная где угодно ссылка на встречу сама появляется в блоке («Ссылка Zoom из буфера · войти»).
- Перед встречей — звук уведомления (выключается в Настройки → «Созвоны»).
- **Из календаря**: в событии ищется ссылка Zoom, Google Meet, Teams, Яндекс Телемоста, Jitsi, VK Звонков,
  SberJazz, Контур.Толка, Webex, Skype, Discord, Slack, Telegram, Whereby, WhatsApp. Ближайшая встреча — карточкой
  с обратным отсчётом и кнопками «Подключиться на ПК» / «С телефона», остальные — списком на день.
  За N минут (Настройки → Созвоны) встреча появляется в строке сверху, тап по ней подключает.
- **Идущий звонок на ПК** DeskDash.exe находит сам, в любом приложении: кто сейчас занял микрофон (Windows
  записывает это для настроек конфиденциальности, Linux — потоки PipeWire/PulseAudio). Zoom, Teams, Телемост,
  Discord, Telegram, WhatsApp, Slack, Webex, Skype и браузер с Meet/Телемостом/Jitsi. Карточка: сервис, название
  встречи, таймер, камера вкл/выкл и кнопки: микрофон (системный, работает в любом приложении и показывает
  настоящее состояние), камера, демонстрация, рука, выйти (сочетания клавиш самого приложения).
- **Экран ПК на телефоне**: кнопка «На телефон» в карточке звонка, тап по строке сверху или `⋮` → «Экран ПК на
  телефоне». Экран компьютера целиком, вебка поверх в углу (двигается пальцем, тап — поменять местами с экраном),
  внизу кнопки звонка, «Чётче/Быстрее» — качество. Вебка через ffmpeg (`winget install ffmpeg`) или OpenCV.
  На ПК выключается: DeskDash → Настройки → «Экран на телефоне».

## Статистика дня

Блок «День» и `⋮` → «Статистика дня»: сколько ты за компьютером по часам (график), с какого и до какого времени,
в каких приложениях, сколько и каких созвонов, неделя для сравнения; с дашборда — сколько играла музыка и
сколько треков, нажатия по умному дому; из календаря — встречи по плану. Время за ПК считает DeskDash.exe
(`%APPDATA%\DeskDash\days.json`, месяц истории): две минуты без мыши и клавиатуры ещё считаются, созвон — всегда.

## Профили и столы

- **Профили**: у каждого человека свои тема, календарь, ПК, умный дом и столы.
  Настройки → «Профиль»: «Новый» (копия текущего или с нуля), «Переименовать», «Удалить».
  На экране профиль переключается кнопкой внизу или через `⋮` → «Профиль».
- **Столы**: несколько экранов, они листаются свайпом влево/вправо по свободному месту
  (не по часам и не по сетке месяца) или точками внизу экрана.
- `⋮` → «Столы и блоки» (или Настройки → «Столы и блоки»): добавить, переименовать, переставить
  и удалить столы. Каждый стол состоит из колонок (у каждой своя ширина), в колонках блоки:
  часы, календарь, музыка, компьютер, умный дом, созвоны, день. Блоки двигаются кнопками ↑ ↓ ← →, ↕ меняет высоту
  («авто» по содержимому или доля колонки ×1…×3). Блок «Умный дом» можно ставить несколько раз
  («Кухня», «Спальня»…).
- Настройки из прошлых версий становятся первым профилем, а прежний экран — его первым столом.

## Умный дом

Блок «Умный дом» показывает плитки: свет, розетки, выключатели, шторы, кондиционеры и термостаты,
датчики (температура, влажность, двери, протечки, движение) и сценарии.

- **Тап по плитке**: включить/выключить, запустить сценарий. Термостат и замок открывают карточку.
- **Долгий тап**: карточка устройства: вкл/выкл, яркость, тёплый/холодный белый, цвет,
  целевая температура.
- Устройства для блока: «Столы и блоки» → «Устройства…» в блоке «Умный дом» (галочки по списку,
  он сгруппирован по комнатам).
- В заголовке блока: температура дома (средняя по датчикам и термостатам), сколько горит света и «Выключить всё».
- **Автоматизации** (Настройки → «Умный дом»): лампа или сценарий на время созвона (на телефоне или ПК);
  что выключить, когда наступает ночь; «рассвет» — лампа плавно разгорается за 10–45 минут до конца ночи.
  Работают, пока дашборд открыт.

Сверху экрана — **живая строка**: идущий созвон с таймером, созвон через пару минут, печать
(«P1S · 45% · 1 ч 20 мин · до 15:40»), стирка, уборка, тревоги (протечка, дым, ошибка печати) красным.
Тап открывает карточку устройства. Выключается в Настройки → «Экран и ночь».

### 3D-принтер Bambu Lab
Настройки → «3D-принтер» → «Найти принтер». Дашборд подключается к принтеру напрямую по локальной сети
(MQTT, порт 8883), как Bambu Studio: облако, ПК и Home Assistant не нужны. Код доступа подтянется из Bambu Studio,
если на ПК запущен DeskDash.exe, иначе он на экране принтера (Настройки → WLAN). Плитка: процент, время
до конца, картинка с камеры (P1, A1); долгий тап — слой, температуры сопла и стола, «Пауза», «Продолжить»,
«Остановить», «Подсветка». Начало и конец печати появляются в живой строке.

### Принтеры, пылесосы, камеры и техника из Home Assistant
Интеграции Bambu Lab, OctoPrint и Moonraker/Klipper становятся одной плиткой принтера с прогрессом и кнопками,
стиральные/сушильные/посудомоечные машины с датчиком «осталось» — плиткой с таймером, пылесосы — «Убрать» /
«На базу» / «Пауза», камеры — плиткой с картинкой. Через хаб всё то же самое, кроме картинок камер.

### Home Assistant
Настройки → «Умный дом: Home Assistant»: адрес как в браузере (`http://192.168.1.20:8123`) →
«Войти в Home Assistant», откроется обычная страница входа. Можно вместо этого вставить
долгосрочный токен (профиль пользователя в HA → «Безопасность» → «Долгосрочные токены доступа»).
Состояние обновляется каждые 5 секунд.

### Яндекс
Нужно один раз создать своё приложение на [oauth.yandex.ru](https://oauth.yandex.ru):
«Создать приложение» → веб-сервисы, Redirect URI `https://oauth.yandex.ru/verification_code`,
доступы «Умный дом»: просмотр и управление (`iot:view`, `iot:control`). ClientID вставить в
Настройки → «Умный дом: Яндекс» → «Войти в Яндекс». Токен действует год. Используется официальный
API `api.iot.yandex.net`, состояние обновляется раз в 15 секунд и сразу после нажатия.

## Управление на телефоне
- Свайп вверх/вниз у правого края экрана: громкость. У левого края: яркость
  (сбросить на системную: Настройки → «Яркость как в системе»).
- Свайп по часам влево/вправо: стиль часов (цифровые, стрелочные, перекидные, столбиком,
  словами, кольцо дня).
- Двойной тап по часам: следующая тема (Мокко, Латте, AMOLED, Шалфей, Океан).
- Долгий тап по часам или `⋮`: настройки.
- Календарь: `‹ ›` листают дни, «Месяц» открывает сетку на месяц (свайп листает месяцы,
  тап по дню открывает его), тап по заголовку возвращает на сегодня. Через 3 минуты без касаний
  календарь сам возвращается на сегодня.
- Тап по событию: подробности. Тап по карточке музыки: открыть Spotify.
- Кнопка устройства рядом с плеером: выбор, где играет Spotify (нужен вход в Spotify в DeskDash.exe).
  Если музыка играет на другом устройстве, карточка показывает трек и обложку оттуда,
  а кнопки ⏮ ⏯ ⏭ управляют им через ПК.
- Ночью (по умолчанию 23–7) включается тёмно-красная тема и минимальная яркость.
- Заставка: Настройки → «Открыть настройки заставки» → DeskDash, «Во время зарядки».

## Сборка

```bash
cd android
JAVA_HOME="C:/Program Files/Java/jdk-17" ./gradlew assembleDebug
```

```bash
cd pc-agent
python -m pip install pyinstaller pystray pillow
python build_exe.py
```

Без интерфейса агент тоже запускается: `python pc-agent/deskdash_agent.py`.

API агента (заголовок `X-Token`): `GET /api/info`, `/api/stats`, `/api/calls`, `/api/day`, `/api/stream/info`,
`/api/stream/screen` и `/api/stream/camera` (MJPEG; `?once=1` — один кадр экрана), `/api/bambu`;
`POST /api/macro/<id>`, `/api/calls/<mute|unmute|mute_toggle|show|camera|share|hand|leave>?call=<id>`,
`/api/open` с `{"url": "<ссылка на встречу>"}`.
